Seed from a recording

A recording fills in deployments you never had on screen. It carries no market cap and no migration, so imported coins count toward the total and never toward the ran count — the ratio will drop, and that is it getting more honest, not worse.

Produce one with npm run record -- --out seed.ndjson. Both newline-delimited JSON and a plain JSON array are accepted.
